# 3D tour model

`parkvision-lot.blend` is the source for `src/pages/public/tour/assets/parkvision-lot.glb`,
the scene rendered by the `/tour` page (`src/pages/public/tour/ParkingScene.ts`).

The two car prototypes are generated by `car_builder.py` (lofted body with subdivision and
boolean wheel arches, lofted cabin with inset glass and rubber frames, lathed tyres and 5-spoke
rims with discs and calipers). To rebuild them, run it in Blender's Python console with this
file open:

```python
exec(open("car_builder.py").read())
P = bpy.data.collections["Prototypes"]
build_car("Sedan", SEDAN, P, (0, 80, 0))
build_car("SUV", SUV, P, (6, 80, 0))
```

Re-export after editing: File → Export → glTF 2.0, format **GLB**, **+Y Up** on,
cameras and lights off, apply modifiers on. Overwrite the `.glb` above.

Positions in `tour/timeline.ts` are in Blender coordinates (x right, y into the lot,
z up); the scene maps them to three.js as `(x, z, -y)`.

`ParkingScene.ts` looks these objects up by name, so keep them when editing:

| Object | Used for |
| --- | --- |
| `Car_Sedan`, `Car_SUV` | car prototypes, cloned per car; nose points +Y |
| `*_PlateAnchorF`, `*_PlateAnchorR` (car children) | where the plate texture is attached |
| material `CarPaint` | recoloured per car |
| `Barrier_Entry_Pivot`, `Barrier_Exit_Pivot` | rotated to lift the arms |
| `ANPR_Entry_Eye`, `ANPR_Exit_Eye` | ANPR camera position for the scan cone and picture-in-picture |
| `MonCam_B1_Eye` | monitor camera over row B (presence chapter); the other `MonCam_*` are decoration |
| `Anchor_LED_Entry`, `Anchor_LED_Exit`, `Anchor_Guide`, `Anchor_Pylon` | live LED panels |
| `Anchor_FasciaSign`, `Anchor_BuildingSign` | brand signs |
| `Anchor_Entry_Lamp`, `Anchor_Exit_Lamp` | barrier status lamps |
